# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**.

The canonical text is maintained at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>. By participating in this project — opening issues, submitting pull requests, joining discussions — you agree to abide by it.

## Scope

The Code of Conduct applies in all project spaces, including the GitHub repository (issues, pull requests, discussions, commit messages, code review), any associated communication channels, and any in-person or virtual events where someone is representing the project.

## Enforcement

Concerns can be raised privately by opening a [GitHub Security Advisory](https://github.com/Marazii/research-co-pilot/security/advisories/new) on this repository (the same channel used for security disclosures — see [SECURITY.md](SECURITY.md)). Reports are reviewed within a reasonable timeframe; outcomes follow the enforcement-ladder guidance in the canonical Contributor Covenant text.
